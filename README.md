# Guia de Stories da Mari

Página (PWA) com o guia de stories da Mariana Lopes Estética.

- A página é estática e fica aqui no GitHub Pages.
- O conteúdo do guia e os números vêm do n8n: `https://n8n.gontify.com.br/webhook/guia-mari?f=dados`.
  - Texto do guia e foco da semana: tabela `guia_mari_conteudo` no n8n.
  - Números: abas API da planilha Central de Conteúdo e Campanhas.
- Os checkboxes ficam salvos no celular (localStorage) e zeram quando muda a semana.
